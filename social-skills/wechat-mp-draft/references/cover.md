# 公众号封面规范与生成

## 规格

| 用途 | 比例 | 尺寸 | 说明 |
|---|---|---|---|
| 首图封面 | 2.35:1 | 900×383 起（模板 900×383） | 单图文 / 多图文头条位，信息流里最显眼 |
| 次图封面 | 1:1 | 500×500 | 多图文第 2 篇起，大字少信息 |

- 封面在信息流被压得很小：主标题 ≤2 行、每行 ≤8 个全角字，副标题一句话；不放二维码/联系方式。
- 后台上传封面后可拖动裁剪，API 直传按原图存储、展示端按 2.35:1 裁切——所以模板固定 2.35:1 画布，关键内容放安全区，**不要改动画布宽高**。
- 上传后微信还会压缩：导出不要低于 900 宽；2x 截图（1800×766）更清晰，直接可用。

## 路径 A：HTML 模板渲染（默认；含中文大字的封面必走）

模板：`assets/templates/cover-wide.html`（首图）/ `cover-square.html`（次图），品牌色板见 `assets/brand.md`（模板 `:root` 已内置变量，勿逐处硬编码）。

1. 复制模板到工作目录，替换【】占位文字——**占位符长度即安全上限**，长了必溢出。
2. chrome-devtools 渲染：`new_page`（file:// 路径）→ `resize_page` 到精确尺寸 → `take_screenshot` 存 PNG 到文章目录。
3. 目检：文字溢出、截断、对比度不足、占位符【】残留——发现即改 HTML 重渲。

字号下限：首图主标题 ≥58px、副标题 ≥27px；次图主文案 ≥90px、品牌名 ≥30px。安全边距 ≥48px。金色只作结构点缀（栏目标签、圆环、分割线），青蓝作重点词强调——色板角色规则见 brand.md。

## 路径 B：AI 生图（纯视觉封面，画面无文字）

ark-image-gen 出图后裁到 2.35:1。首选 `--ratio 47:20`（恰为 2.35:1，脚本按比例换算像素）；若该比例被拒，退回 21:9 再裁高度：

```bash
bash <ark-image-gen 技能目录>/scripts/image_gen.sh "深蓝科技感抽象背景，霓虹青蓝光效，大面积留白，无任何文字、无字母、无标志" -m 5 --ratio 47:20 -s 2K -o cover_raw.jpg

# 21:9 兜底：竖向中心裁剪到 2.35:1
python3 -c "from PIL import Image; im=Image.open('cover_raw.jpg'); w,h=im.size; th=int(w/2.35); y=(h-th)//2; im.crop((0,y,w,y+th)).save('cover.png')"
```

- 提示词**必须**含「无任何文字、无字母、无标志」——AI 中文字几乎必错；需要大字标题就回路径 A。
- 次图 1:1 直接 `--ratio 1:1 -s 2K`。
- 日常封面优先 `5flash`（便宜快速），要画质用 `5`。

## 上传

封面文件路径填进 draft.json 的 `cover_image`（相对 draft.json 所在目录），mp_submit.py 提交时自动 add_material 换取 thumb_media_id；已有永久素材时直接填 `"thumb_media_id": "…"` 跳过上传。正文图与封面是两回事：正文图走 uploadimg（拿 URL），封面走 add_material（拿 media_id），脚本已自动分流。
