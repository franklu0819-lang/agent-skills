# 社交贴图 + 文案（内容给定 → 3:4 卡组 + 文案包）

核心方法：**AI 只生成无文字背景，所有文字用 PIL 本地排版**。中文零错别字由本地排版保证；
改文字/排版 = 改代码重渲染（零 API 成本），绝不让 AI 重新生成整图。

## 输入契约（本技能不收集内容）

动手前必须已有：核心事实清单、关键数据（含单位与口径）、每条信息的来源、发布日期。
缺任何一项 → 停下向用户要素材，或先完成调研再回来。
**严禁**为凑卡片编造或推断数据；官方未公布的数字标注「未公布」，宁可留白。

## 流程

### 1. 规划卡组（3~5 张，3:4）

- 封面：大标题（可中英混排）+ 一句话副题 + 3 个关键数据 chip + 信息来源
- 信息卡 2~4 张，按内容选型：看点列表（编号圆徽）/ 多系列对比条形图 / 价格+时间线 / 面板要点
- 每张左下角信息来源、右下角页码 `0X / 0N`
- 信息设计：对比图必须带参照系（竞品/基线），诚实包含落后项（更可信）；数字统一小数位

### 2. 生成背景（ark-image-gen，只生成无文字背景）

```bash
STYLE="竖版手机海报背景，深邃的蓝紫色星际星云渐变，细腻光斑粒子，高级科技感，极简主义构图，大面积干净留白，柔和辉光，电影级光感，画面中无任何文字、无字母、无标志，8k画质"
bash <ark-image-gen技能目录>/scripts/image_gen.sh "$STYLE，<每张不同的场景后缀>" -m 5 --ratio 3:4 -s 2K -o bg/bg_1.jpg
```

- 统一风格 = 共用 STYLE 前缀 + 每张不同场景后缀（星环/极光/地平线等），一次 bash 循环跑完
- 提示词**必须**包含「无任何文字、无字母、无标志」
- 产物 1774×2365（3:4、2K 档），每张 ≈16k tokens
- Windows：脚本内部调用 `python3`，需垫片 `~/.local/bin/python3` → `py -3`（本机已建）

### 3. 本地排版合成

复制 `scripts/example_deck.py` 到工作目录改名为 `compose.py`，替换其中的数据与文案、按需增删卡片；
排版工具全部来自同目录 `scripts/cardkit.py`，不要重写。运行 `py -3 compose.py`。

硬规则（每条都踩过坑）：

1. 胶囊/徽章内文字必须按墨迹包围盒居中（`cardkit.pill` 已内置）——用字体度量推导会整体偏下。
2. 中文逐字断行；西文/数字串（`C/C++`、`100 万+`、`gemini-4`）整词原子不可拆（`cardkit.wrap`）。
3. 浅色底配深字：luminance = 0.299R+0.587G+0.114B，>140 用深字（`pill` 自动）；正文白字必须压深色面板（alpha≥175），对比度 ≥4.5:1。
4. 行距宁松勿挤：同块两行文字中心距 ≥1.6 倍字号；内容底部与页脚之间留 ≥150px（1080 尺度）。
5. 多系列对比用色相分离的颜色（如蓝/绿/橘/紫），图例-条形-数值三处同色；灰阶在缩略图下不可辨。
6. 数值格式统一（建议一位小数）；条形图填充长度必须与数值成比例。
7. 术语用通行译法，不做直译（introductory period → 首发优惠期，不是「介绍期」）；百分比写「为 X 的 5%」，不写「95% 折扣」（易被读成 95 折 = 付 95%，语义相反）。
8. 字体：中文粗 `msyhbd.ttc`、中文 `msyh.ttc`、拉丁大标题 `ariblk.ttf`、拉丁粗 `arialbd.ttf`（均在 C:/Windows/Fonts）。

### 4. 视觉验收（必过，不省）

渲染后派只读视觉子智能体（vision 或 *-visual-judge）逐张验收，清单按序：
文字正确性（无错别字/乱码方块/重叠/截断溢出）→ 可读性（对比度）→ 排版（对齐/间距/页码）→ 信息设计（层级/参照系）。
每张输出 JSON 判定 + 坐标证据；overall fail → 改 `compose.py` 重渲染 → 回**同一个**子智能体复检，直到 pass。

几何类问题（居中/间距/重叠）修复时用 PIL 像素测量自证（文字 ink bbox vs 容器 bbox 的中心偏差），
不靠目测；验收员通过 ≠ 用户通过，用户挑刺时同样走「测量 → 改代码 → 复检」。

### 5. 文案包（文案.md）

结构：小红书（标题 3 选 + 正文 + 标签）｜公众号（标题 3 选 + 导语 + 正文要点）｜
事实核对清单（贴图每处表述 ↔ 来源逐条对应）｜常见疑问预答（预判评论区质疑并给准确答案）。
**图文口径必须一致**：图里改了数字/译法，同步改文案。

**公众号发布文字硬限制：≤ 1000 汉字当量**（公众号图片消息形态的文字上限）。当量口径与标题一致：
汉字/全角标点 =1，英文字母/数字/半角符号 =0.5。交付前必须脚本验证（预期 ≈950~1000，超限即改）：

```bash
python3 - <<'EOF'
import unicodedata, re
text = open("文案.md", encoding="utf-8").read()
m = re.search(r"\*\*正文（整段显示在贴图组下方[^*]*\*\*\n(.*?)\n---", text, re.S)
clean = "".join(ln.lstrip("> ").rstrip() + "\n" for ln in m.group(1).splitlines() if ln.strip())
t = clean.replace("\n", "")
total = sum(1 if unicodedata.east_asian_width(c) in ("F", "W") else 0.5 for c in t)
print("汉字当量: %.1f / 1000 -> %s" % (total, "OK" if total <= 1000 else "OVER"))
EOF
```

超限时只精简行文（连接词、重复表述、冗余修饰），**不得砍关键事实与口径限定**；
标题候选、导语（≤120 字）、事实核对清单、疑问预答不占该额度。

## 环境

- Windows + Git Bash；Python 用 `py -3` 调用
- 产出：`final/<名称>.png` + `.jpg`（1080×1440，Lanczos 缩自 native 1774×2365）
- 成本：只有背景生成花 API（每张 ≈16k tokens）；文字与排版迭代零成本
