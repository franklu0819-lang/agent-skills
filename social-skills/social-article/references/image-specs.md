# 正文配图规范与渲染流程

## 尺寸速查

| 用途 | 尺寸（px） | 模板 |
|---|---|---|
| 正文小节横幅 | 900×500 | `assets/templates/banner-body.html` |
| 金句卡 / 朋友圈图 | 1080×1080 | `assets/templates/quote-card.html` |

- **公众号文章封面**（2.35:1 首图 / 1:1 次图）的规范与模板在 wechat-mp-draft 技能（其 references/cover.md），随排版提交流程一起出。
- **头条文章封面**按 16:9：AI 生图直接出，或横幅模板把画布改成 1280×720。
- **3:4 贴图组**（多张信息卡 + 配套文案）不在本技能，交给 social-cards 技能。

## 设计规则

- **一张图一个信息层次**：横幅只放小节编号 + 主标题（≤ 2 行）+ 一句话副题；金句卡只放一句金句 + 署名。
- **字号下限**：900 宽横幅主标题 ≥ 60px、副标题 ≥ 27px；1080 方图主文案 ≥ 48px、署名 ≥ 26px。低于下限在手机上会糊。
- **占位符长度即安全上限**：模板里【】占位符的字符数就是该位置文字量的上限，替换内容不要明显长于占位符，长了必溢出（横幅主标题每行约 12 个全角字符是安全线）。
- **安全边距**：内容距边缘 ≥ 48px（横图）/ ≥ 64px（方图）。
- **对比度**：文字与背景 ≥ 4.5:1（WCAG AA）。深色底配白字最稳。
- **品牌色**：模板已内置品牌色板（`assets/brand.md`：深蓝底 + 电光青蓝 `#82DEF5` 强调 + 金色 `#F2D183` 结构性点缀），默认直接用，勿改；仅当用户明确指定其他品牌色时才整体替换 `:root` 变量。
- **字体栈**：`"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`（模板已内置，勿改）。
- 不放二维码/联系方式——这类元素在信息流会被压小到不可读，只放正文长图或海报且 ≥ 200px。

## AI 生图配图（ark-image-gen）

插画/场景类配图（无文字）用 ark-image-gen；提示词**必须**包含「无任何文字、无字母、无标志」——AI 生成中文几乎必错，含大段中文文字的图一律走 HTML 模板渲染：

```bash
bash <ark-image-gen 技能目录>/scripts/image_gen.sh "<场景描述>，无任何文字、无字母、无标志" -m 5flash --ratio 16:9 -s 2K -o <slug>/fig-01.jpg
```

- 日常配图优先 `5flash`（快、便宜、支持小图），要画质再换 `5` / `5pro`。
- 正文配图横图 16:9 或 3:2；金句卡无字背景用 `--ratio 1:1`。
- 响应 URL 是临时签名地址，脚本已自动下载到本地，交付本地路径。

## 渲染流程（chrome-devtools MCP）

模板改好后按此流程出图：

1. `mcp__chrome-devtools__new_page`，url 填 `file://` + HTML 绝对路径。
2. `mcp__chrome-devtools__resize_page`，把页面 resize 到模板精确尺寸（如 900×500）。
3. `mcp__chrome-devtools__take_screenshot`，`filePath` 指向 `docs/marketing/<slug>/` 下的 PNG 输出路径。若 `filePath` 被 workspace-root 配置拒绝（报 Access denied），降级为**不带 filePath 的内联截图**，再按返回的 artifact 路径/URL 用 `cp`（本地路径）或 `curl -L -o`（CDN URL）落到目标位置。
4. 打开 PNG 目检：文字溢出、截断、换行位置奇怪、对比度不足、占位符【】残留——发现即改 HTML 重渲，不带病交付。

注意：

- Retina 屏截图是 2x 物理像素（如 1800×1000），比例不变、更清晰，直接可用。
- 文字量增多时优先**缩小内容**（精简文字），不要缩字号突破下限。

## 自建新模板

模板不满足需求时（如节日海报需要插画位），从最近的模板复制修改，并遵守：画布尺寸固定、字体栈不变、字号/边距/对比度三规则不破。用户提供了 logo/插画文件时，放入 `docs/marketing/<slug>/` 用相对路径引用。
