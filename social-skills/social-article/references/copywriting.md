# 文章写作规范（公众号 + 头条号）

## 平台差异速查

| 维度 | 公众号 | 头条号 |
|---|---|---|
| 标题 | ≤32 汉字当量（微信计数：汉字 2 字符/英文 1 字符、上限 64 字符，当量 ×2 恰好对齐；见下节） | 5–30 个字；可写 2–3 个候选供双标题 A/B |
| 摘要 | ≤120 字，显示在会话分享卡片；不填默认抓正文前 54 字 | 无摘要位，平台自动截取正文开头——开头 100 字即卖点 |
| 正文结构 | 钩子 → 3–5 个小标题分段 → CTA | 开头即亮点 → 小标题 + 配图 → 结尾引导评论 |
| 配图 | 横幅小节图 + 金句卡（见 image-specs.md） | 横图 ≥3 张利于推荐（16:9 / 3:2） |
| 分发逻辑 | 社交分发：标题与摘要决定打开率 | 算法分发：完读率与互动权重高，标题党会被打压 |
| 合规重点 | 广告法极限词、诱导分享 | 同左；医疗/财经/时评等资质领域慎写 |

标题候选：公众号 3–5 个、头条 2–3 个，每个候选标注当量值。当量注记写在手法括号内（`（悬念 · 17.0 当量）标题`）或行尾（`标题 —— 17.0 当量`），len_check 两种都会自动剥离，不计入标题长度。

## 公众号标题（≤32 汉字当量，硬约束）

当量口径：汉字/全角标点 =1，英文字母/数字/半角符号 =0.5。微信标题按「汉字 2 字符、英文 1 字符、上限 64 字符」计数，**当量 ×2 恰好等于微信字符数**，故 32 当量即平台真实上限，无另设内线。〔2026-10-08 勘误：原误作 20 当量——那是贴图标题（social-cards 技能）的版面限制，不适用于文章标题〕。信息流里超长标题会被截断，影响打开率；手机通知栏与会话列表只露前 13 字左右——信息量最大的词放前面仍是写作纪律。

交付前必须跑 `scripts/len_check.py` 验证（用法见脚本头注释），超限只精简措辞，不砍信息量。禁止虚假承诺——标题党的打开率是一次性的，掉的是信任。

五个常用公式（每次从中选 3–5 个手法产出候选）：

| 手法 | 公式 | 示例 |
|---|---|---|
| 数字盘点 | 「N 个 ___，帮你 ___」 | 5 个被低估的效率工具，帮你每天省出 1 小时 |
| 痛点提问 | 「还在 ___ 吗？」 | 还在手动整理周报吗？ |
| 悬念缺口 | 「___ 的真相，是 ___」 | 那些准时下班的人，都在偷偷做这 3 件事 |
| 利益承诺 | 「看完这篇，你会 ___」 | 看完这篇，你会重新规划明年的预算 |
| 身份代入 | 「写给每一个 ___ 的你」 | 写给每一个"周五晚上还在改方案"的你 |

## 摘要（≤120 字）

显示在分享卡片与"不打开正文"的场景。一句话说清「这篇讲什么 + 读者得到什么」，不剧透结论，不写"本文介绍了……"式的论文腔。

## 正文结构

**公众号**——总—分—总：

1. **开头钩子（前 3 行定生死）**：场景痛点、反常识事实、直接给利益点，三选一。不要"随着社会的发展"式引入。
2. **主体**：3–5 个小标题，每节只讲一件事；小标题连读要能成一条逻辑线。
3. **结尾 CTA**：三选一——引导在看/转发、引导留言、引导关注。只放一个，全堆等于没有。

**头条号**——为完读率写：

1. **开头 100 字**：直接给结论或利益点（算法据开头决定推荐量）。
2. **主体**：小标题清晰，每 2–3 段配一张横图；一段 ≤3 行。
3. **结尾**：抛一个明确的评论问题（互动权重高），不写诱导关注类字眼（平台限流）。

## 排版约定（手机阅读优先）

- 段落 ≤ 3 行（约 60 字），一段一个意思。
- 关键结论句加粗，全文加粗 ≤ 5 处。
- 引用块用于金句或数据来源，不用于长段正文。
- emoji 适度：专业调性每屏 ≤ 1 个，活泼调性 ≤ 3 个。
- 公众号正文用标准 Markdown 的**受限子集**书写，排版交给 wechat-mp-draft 技能的 typeset.py 完成（微信编辑器只认内联样式，不要手写 HTML；受限子集见该技能 references/typesetting.md）。

## 合规自检（写完逐条过）

- **广告法极限词**：最、第一、顶级、绝无仅有、国家级、销量冠军、全网最低……改写为可验证表述（"上市首月售出 2 万件"而非"销量第一"）。
- **医疗功效**：普通商品不得声称治疗、根治、消炎、降三高。
- **金融承诺**：不出现保本、稳赚、收益率保证类表述。
- **诱导分享**：不写"转发到 3 个群领取福利"（违反微信运营规范，可能限流）；"分享给需要的朋友"是安全表述。
- **头条标题**：不夸张恐吓、不与内容不符（标题党降权）。
