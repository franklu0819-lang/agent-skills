# 抖音账号级深度分析

把一个抖音账号变成「账号画像 + N 个视频全文转写 + 内容体系归纳 + 三层评判 + 结合用户情境的建议」的完整交付物。2026-09-28 实测跑通（姜胡说账号，490 万粉，3 个本人视频 + 2 个仿写对照，端到端约 1 小时）。

前置依赖：**douyin-video-analysis 技能**（单视频流水线：下载、抽音轨、转写、fetch.sh 脚本——本技能直接复用，不重复实现）。

## 流程总览

```
账号定位（外部搜索，勿走站内搜索）→ 主页元数据 → 视频清单与选取
→ 作者归属验证（关键防线）→ 逐视频走 douyin-video-analysis 流水线
→ 外部背景与争议调研 → 账号级归纳与评判 → 建议
```

## Step 1 账号定位：只用外部搜索，不走站内

**不要用 douyin.com/search**——搜索页（type=user/video）未登录会触发验证码中间页，且反复访问会升级风控，连带污染同一浏览器会话的视频页访问。

正确路径（Exa 的 web_search_exa 效果最好，其次 WebSearch）：

1. 搜 `<账号名> 抖音主页 douyin.com/user`，目标拿到主页链接 `douyin.com/user/MS4wLjAB...`（sec_uid 是账号唯一标识，后续验证作者归属全靠它）；
2. 同时收集第三方数据平台的账号页（weelume、飞瓜 dy.feigua.cn、新抖、抖查查）——粉丝数、作品数、飞瓜指数、更新频率；
3. 搜 `<账号名> 是谁 / 背景 / 履历 / 争议 / 翻车`——背景履历、变现结构（卖课/星球/带货）、负面记录一次查全。**争议记录是必查项**：头部博主几乎都有公开的批评帖/翻车事件，只看正面材料会严重失真（实测案例：姜胡说 2024 荐股争议，第三方资料里有、本人内容里永远不会有）；
4. 意外的高价值信源：粉丝整理的资料库（语料 Skill、飞书直播逐字稿、豆瓣/雪球书评）——直播逐字稿的信息密度常高于短视频，且免费。

## Step 2 主页元数据

`new_page` 直接打开 `https://www.douyin.com/user/<sec_uid>`（无需登录），从快照拿：昵称、简介（注意"反向锚"话术，如自贬式简介）、粉丝数、获赞数、作品数、认证类型。A/B/C 层基础画像在此成型。

**已知坑**：主页的作品网格（`[data-e2e="user-post-list"]`）可能显示"服务异常，重新刷新拉取数据"——这是作品列表 API 被风控，**reload 无效，不要反复重试**（会加重风控）。降级走 Step 3 的外部搜索。

## Step 3 视频清单与选取

优先级从高到低：

1. **主页网格可用时**：evaluate_script 滚动加载后提取 `a[href*="/video/"]` 的 ID 与标题（注意区分：推荐流链接混在页面里，只取 user-post-list 容器内的）；
2. **网格被风控时**：外部搜索 `<账号名> douyin.com/video`（Exa）拿视频直链——实测能搜到标题+部分文案+热门评论，常够初筛；
3. 抖音精选频道 `jingxuan.douyin.com` 的收录页（正文常带完整口播稿，可先读文字再决定是否下载）。

**选取原则**（目标 3-5 个）：
- 覆盖账号的主干品类（若账号有多条内容线，每条线至少 1 个）；
- 兼顾数据头部（互动最高的爆款——账号的流量密码）与近期发布（当前状态）；
- 长视频（8 分钟+）信息密度通常远高于短视频，优先选；
- **先外部搜索读标题/文案初筛，再进浏览器下载**，省会话时间。

## Step 4 作者归属验证（本技能的核心防线）

**外部搜到的视频不一定是本人发的**——带 `#账号名` 话题标签的粉丝仿写/学员作业内容会混进搜索结果，且文案高度模仿原主（实测：2 个仿写视频里 1 个连标题都带"姜胡说"标签，口播方法论几乎照搬）。

每个视频打开后、下载前，三重验证：

1. **sec_uid 比对（硬验证）**：视频页内 `a[href*="/user/MS4"]` 的 href 与主页 sec_uid 比对，不一致即非本人；
2. **转写后人设线索**：自称身份与博主是否矛盾（实测信号："我一个普通的妈妈" vs 姜胡说的中年男性履历）；
3. **数据特征参考**：本人爆款视频赞 3-5 万 vs 仿写 8-25 赞（弱信号，仅辅助——本人也有低数据视频）。

**仿写内容不要直接丢弃**：它是"方法论成材率"的一手证据（多少人模仿、模仿者数据如何），作为对照样本写进分析，比任何推理都硬。

## Step 5 逐视频处理

走 douyin-video-analysis 流水线。账号级场景的补充经验：

- **blob: 流（MSE）概率高**：`video.currentSrc` 为 `blob:` 时，从 `performance.getEntriesByType('resource')` 过滤 `douyinvod.com` 拿分轨地址（`media-video-hvc1` 视频 + `media-audio-und-mp4a` 音频），**返回完整 URL，不要在脚本里 slice 截断**（截断即 403/坏文件）；
- 分轨用 fetch.sh 分别下载后 `ffmpeg -i video.m4s -i audio.m4s -c copy out.mp4` 合成；音轨可能只有几百 KB（正常，阈值已放宽）；
- **串行处理**：一个视频完整落地（下载+转写启动）再开下一个浏览器导航；直链带签名有时效，提取后立即下载，不要攒批；
- 长视频转写用 run_in_background 并行等结果，利用等待时间做下一个视频的浏览器提取；
- **ASR 英文误听模式**要心里有数：专有名词常被听成中文谐音（Claude Code →"龙虾/爱马仕"、ChatGPT →"OpenCL"）——分析时先识别这类系统性误听再解读观点，别把误听当术语引用。

## Step 6 账号级分析框架

### 交付物目录

`调研-<账号名>账号分析/`，视频与转写按 `01-<主题>.mp4` / `01_转写-<主题>.txt` 命名，非本人视频文件名标注 `作者XXX` 或 `粉丝仿写`。

### 分析结构（六段）

1. **账号画像**：数据（粉丝/获赞/作品/认证）、简介的话术设计、履历背景、受众画像、变现结构推断（课程/星球/带货/广告的证据链）；
2. **内容体系归纳**：跨视频提炼——内容支柱及配比、反复出现的方法论框架（公式化表达）、话术与称谓模式（如"老伙计"式社群称谓）、选题结构规律（评论区的"我发现他的视频是有整体结构的"类评论是线索）；
3. **三层评判**：✅ 站得住（与公开数据/常识互证）/ ⚠️ 方向对但说过头（虚荣指标、幸存者偏差、窗口期红利、以偏概全——逐一用数据校准）/ ❌ 盲区（变现真实数据、失败率、合规、利益相关）；
4. **对照样本**：仿写/学员内容的成材率证据；
5. **争议记录**：外部调研到的负面事件原样呈现，不洗白不放大；
6. **结合用户情境的建议**：读用户当前工作区的项目文档（若有），把账号的可取之处对接到用户自己的处境——泛泛而谈的"学习优点避免缺点"不算合格建议。

### 核查清单（账号级新增项）

- 单视频清单全部适用（虚荣指标/幸存者偏差/商业闭环/利益相关/数据交叉验证）；
- 作者归属是否逐个验证过；
- 变现推断是否有证据链（橱窗/星图/专栏/直播记录），还是纯推测；
- 是否查过争议与负面（没查到也要写"未发现公开负面记录"，注明检索方式）；
- 建议是否真的读了用户的项目上下文。

## 边界与降级

- 主页和视频页都被风控（验证码连环）→ 停止浏览器访问，降级为"纯外部资料分析"（第三方数据平台 + 精选频道文字稿 + 直播逐字稿），明确告知用户覆盖度的损失；
- 只要账号数据画像、不要视频转写 → Step 1-2 后直接输出画像；
- 用户给的是 B站/YouTube/小红书账号 → 本技能不适用（仅抖音），按普通调研处理；
- 账号 <10 个视频或纯直播号 → 建议改用直播逐字稿/切片分析路径，向用户说明。
