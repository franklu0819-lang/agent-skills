# 卷纲编写工作流

卷纲是总大纲与正文之间的桥：把"这一卷讲什么"拆成"每一章发生什么、爽在哪、钩子是什么"。拆到这个粒度，`/novel-chapter` 写每一章时只需要专注文笔。用 TodoWrite 跟踪。

## 前置检查（缺一不可）

- `settings/大纲.md`（已确认）——本卷在分卷框架中的定位
- `settings/风格指南.md`、`settings/世界观/`、`settings/人物/`（已确认）
- 若已有上一卷：读上一卷卷末钩子与 `progress.md` 伏笔台账中"计划在本卷回收"的条目

## Pipeline

1. **定卷框架** — 从大纲分卷框架取出本卷：卷名、舞台、主题、主反派、卷末高潮；确认本卷起止章号（接上一卷末章号 +1；首卷从第001章开始）。
2. **卷内三幕切分** — 本卷自成小三幕（这是全书三幕式在卷层的复用）：
   - **卷一幕（约 20%章节）**：承接上卷钩子 → 立本卷目标与对手 → 第一个钩子事件把主角拉进本卷冲突
   - **卷二幕（约 50%章节）**：三段递进——初步小胜（给甜头）→ 中卷转折（假胜利/真危机，本卷中点）→ 连环受压（盟友出事/资源被夺/身份暴露）
   - **卷三幕（约 30%章节）**：至暗 → 蓄力（伏笔合拢/突破/援军）→ 卷末大高潮（本卷最大爽点，打脸规格配得上反派整卷的嚣张）→ 下卷钩子（新地图/新势力/更大危机露头）
3. **章级排布表** — 逐章填表（这是卷纲的核心产出，模板见下）。每章四要素缺一不可：**事件、冲突/危机、爽点（注明类型）、章末钩子（注明类型）**。
4. **爽点密度自检** — 硬标准：
   - 任意连续 3 章内至少 1 个爽点（不含小甜点）
   - 每 10 章左右 1 个中型高潮
   - 每个大爽点章之前 1–2 章必须是压抑铺垫章（对手立威/主角受挫/资源紧缺）
   - 相邻爽点不同类型（连续两个"打脸"要改一个）
5. **伏笔登记** — 本卷新埋伏笔（编号入台账）+ 本卷回收伏笔（从 progress.md 台账勾销）；检查上一卷遗留未回收伏笔是否安排。
6. **审稿 — dispatch `reviewer`**：排布表对照大纲与人物档案查一致性（人物境界是否超前、反派出场是否与梯队匹配、地点是否在地图动线上）；爽点密度；卷末高潮是否对得起整卷铺垫。
7. **落盘** — 写入 `books/<book>/volumes/第NN卷-<卷名>/卷纲.md`（NN 两位数；目录不存在则创建，同步建 `chapters/` 子目录），文件头 `状态：草稿`。首卷时创建 `books/<book>/progress.md`（台账模板见项目 AGENTS.md），登记本卷伏笔。
8. **GATE** — AskUserQuestion：批准 / 调整（重点让用户扫一眼爽点排布列）。批准后状态改 `已确认`。
9. **交付** — 卷纲路径 + 本卷节奏摘要；建议下一步 `/novel-chapter <book> 第NNN章` 逐章写作。

## 卷纲文件结构（照此模板写）

```markdown
# 第NN卷 · <卷名> 卷纲（状态：草稿）

## 1. 本卷定位
（在大纲分卷框架中的位置 / 舞台 / 主题 / 主反派 / 起止章号与总章数）

## 2. 卷内三幕
- 卷一幕（第0XX–0XX章）：开场承接……本卷钩子事件……
- 卷二幕（第0XX–0XX章）：小胜 → 中卷转折 → 连环受压（各写 3–5 句）
- 卷三幕（第0XX–0XX章）：至暗 → 蓄力 → 卷末高潮与下卷钩子

## 3. 章级排布表（核心）
| 章 | 标题方向 | 主要事件 | 冲突/危机 | 爽点（类型） | 章末钩子（类型） | 出场人物 | 伏笔（埋/收编号） |

## 4. 本卷爽点节奏图
（一行字符串可视化：▁▁█▁▂█… 高低起伏，标注大爽点章号）

## 5. 伏笔台账增补
（新埋：编号+内容+计划回收卷 / 本卷回收：编号）
```

## 排布表填写标准

- **事件**写"谁对谁做了什么"（动作），不写"感情升温"这种无法落笔的抽象话。
- **爽点类型**从固定词表选：打脸 / 逆袭翻盘 / 境界突破 / 获宝奇遇 / 扮猪吃虎 / 身份揭晓 / 复仇雪耻 / 反向碾压 / 感情甜点 / 清扫团灭。
- **钩子类型**四选一：危机钩 / 悬念钩 / 期待钩 / 反转钩。
- 每章事件量按 2200–2500 字容量规划：一章装不下两场大战；转场赶路章合并压缩（网文允许"半章赶路半章事件"）。
- 卷纲 150–350 行（40–80 章的卷）。
