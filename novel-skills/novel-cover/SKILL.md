# 小说封面生成工作流

用 Seedream 4.0 生成符合主流平台规格的竖版封面（先确认题材/书名/作者三要素，作者默认**墨夜寒**），产出高清原图（1536×2048，3:4）+ 平台上传版（600×800 JPG，≤5MB）。用 TodoWrite 跟踪。

## 认证与模型（已验证路线）

- **调用方式**：直连火山方舟公共接入点 REST API（模型名直调，无需部署接入点）：
  `POST https://ark.cn-beijing.volces.com/api/v3/images/generations`，模型 `doubao-seedream-4-0-250828`
- **API Key 解析顺序**（由 `scripts/gen_cover.sh` 自动完成，Key 全程不显示、不落盘）：
  ① 调用参数 `--api-key` → ② 环境变量 `ARK_API_KEY` → ③ `~/.arkcli/config.yaml` 默认 platform 配置档的 `api_key`
- 三处都没有时提示用户：`arkcli auth login volc-sso` 重新登录后即可（不要替用户执行登录，浏览器授权需本人操作）。
- 注意：arkcli 的 `+gen` 在 platform 配置档下强制要求 ep- 接入点 ID，**不要**用 arkcli 出图，统一走本技能脚本。

## Pipeline

0. **三要素确认（硬门禁，未确认不得调用生成 API）** — 逐项收集并向用户复述确认：
   - **题材**：读 `settings/大纲.md` 题材标签；无书目录时问用户。决定主视觉速查表选行与排字模式（暗色题材走 B 模式）。
   - **书名**：读 `settings/大纲.md`；**若标注"暂定名"必须向用户复述并请其当场定名或确认沿用**（封面文字错了要重出整张）。无书目录时问用户；长书名（>8 字）提示将分两行排版。
   - **作者**：默认「墨夜寒」；用户此前明示过笔名则沿用，**不默认不问**以外的来源。
   - 三项齐备后用 AskUserQuestion 一次性复述确认：`题材：X｜书名：《Y》｜作者：Z` → 用户确认 / 修改。确认结果就是后续生成与质检的**核对基准**，中途不得静默更改。
1. **前置检查** — 确定 `<book>` slug 与落盘目录 `books/<book>/covers/`（无书目录的单次任务放用户指定处）；检查认证（脚本自动解析 Key，三处都无时提示 `arkcli auth login volc-sso`，登录需用户本人浏览器授权，不要代执行）。
2. **封面方案** — 从大纲/风格指南取题材与基调，填以下三件（参考下方速查表）：
   - 主视觉：一句话说清画面主体（人物+场景+标志性元素）
   - 配色与氛围：主色 1–2 个 + 光影质感
   - 排字模式：**A 模型排字**（亮色/浅色题材可用）或 **B 无字底图 + 叠字**（`scripts/overlay_text.py`）。
     **暗色/夜景/怪谈题材直接走 B 模式**——实测模型排署名时会自画一块黑底衬放字（裁掉则署名贴底，保留则黑边不可接受），无字底图 + 程序排字是唯一干净解；A 模式中若发现署名下方出现纯黑底衬带，同样立即转 B，不要在 A 模式上打补丁。
3. **生成 3 个候选** — 逐个运行（不同 seed）：
   ```bash
   bash <技能基目录>/scripts/gen_cover.sh \
     --prompt-file /tmp/cover-prompt.txt \
     --out books/<book>/covers --name 封面-v1 --seed 101
   ```
   prompt 按第 2 步选定的排字模式构建：A 模式用模板（含书名与署名）；B 模式生成无字底图，过双门后再用 `overlay_text.py` 排字（`--title`/`--author` 取第 0 步确认值）。产出文件与尺寸由脚本回显。
4. **质检双门 — 先客观后主观，两门都过才算合格**：
   - **客观门（程序化，先跑）**——边缘 letterbox 检测，防"纯黑/纯白边条"（深色夜景题材高发）：
     ```bash
     python3 <技能基目录>/scripts/check_edges.py <生成的图>
     ```
     任一边纯色条 >1.5% 即超标退出码 1。注意：斑驳纹理边框（如"撕纸边"）它测不出来，由主观门兜底。
   - **主观门 — dispatch `vision` 子智能体**（直接 Read 本地图片，不走 CDN/远程视觉接口）：
     派发 prompt 必须自包含：文件路径、**书名基准文本（逐字）**、署名基准「{作者} 著」（第 0 步确认值）、题材预期、七项检查清单（书名字形/署名字形/多余文字水印/人物畸形/构图留白/题材匹配/1-10 评分），要求逐张输出"合格/不合格+最严重问题"。
   - 判废零容忍项：书名错一字、角落"巨手"等画外异物、纯色/纹理边框条、署名被挤换行、**署名贴底（底边距应 ≥3%）**
   - 修复路径优先级：同方向重生成 ≤2 次 → 仍失败**换主视觉构图方向**（特写构图天然撑满画幅、抗 letterbox 最强）→ 程序化修图：无文字且**不承担署名边距功能**的纯色条才可裁除（含署名或紧邻署名上方的黑带是设计边距，check_edges.py 已自动豁免，裁了署名就贴底）；署名贴底/错位可"擦除原字 + PIL 同高度重排"（底边距 3–5%）
   - 复检用 SendMessage 让同一个 vision 继续（保留清单上下文），只给新文件路径
5. **GATE** — 把候选图路径给用户挑 1 张（AskUserQuestion：候选 1/2/3 或全部重生成）。
6. **定稿落盘** — 中选图复制为 `封面-定稿.jpg`，并产出平台版：
   ```bash
   sips --resampleHeightWidth 800 600 -s format jpeg -s formatOptions 90 封面-定稿.jpg --out 封面-平台版-600x800.jpg
   ```
   目录：`books/<book>/covers/`（无书目录的单次任务放用户指定处）。
7. **交付** — 两个文件路径 + 规格说明 + 合规提醒（见下）。

## Prompt 模板（A 模式，核心资产）

```
竖版小说封面插画，{风格}。主视觉：{主视觉一句话}。构图：主体占画面下三分之二，
画面上部为深色或与主视觉同调的背景区域用于书名排版，底部为画面内的暗色区域用于署名。
画面必须铺满整个画幅、边缘到边缘全是画面内容，不得出现白色或浅色边框、边条、
底衬色块、照片白边；画面四角干净，不得有任何物体闯入。
色调：{主色与配色}，光影氛围：{氛围}。文字：画面顶部居中大字书名「{书名}」（长书名
分两行并给出每行内容），{字体气质，如古风宋体/粗黑体}；底部居中一行横排小字
「{作者} 著」（不得换行）。要求：书名字形准确无误；除书名与署名外，
画面中不得出现任何其他文字、水印、边框；人物手指等细节不得畸形。
```
（{作者} 默认「墨夜寒」，以第 0 步用户确认为准）

**模板血泪条款**（实测判废教训，不得删改）：
- 写"留白"模型会画成字面白色底——模板只说"深色/同调背景区域"，白边禁令必须保留
- 四角干净条款防"角落巨手"式异物闯入；暗色场景另需"严禁手持照片式构图、严禁画外伸入物"（巨手两次出现均源于模型把画面当照片）
- 长书名与署名必须显式给分行/单行要求，否则模型自行换行
- 深色夜景题材易出左右纯黑 letterbox 竖条：横向场景要给左右边缘指定具体实体内容；特写构图最抗黑边；生成后必须过 check_edges.py 客观门
- "无边框整幅插画"定位仍可能被加"撕纸边"等纹理边框——主观门重点查四边
- **模型排"XX 著"会自画黑底衬**（暗色题材尤甚）：黑衬裁则署名贴底、留则黑边难看，此题无解，唯一出路是 B 模式（无字底图 + overlay_text.py 程序排字）；含署名的黑带是设计边距，check_edges.py 已豁免，别当 letterbox 裁

B 模式：同模板但删掉"文字：……"两行，改为"画面中不出现任何文字、水印、边框"。

- 平台版固定产出 600×800 JPG（质量 90，实际约 300–500KB，远低于上限）。
- **合规提醒**：按《人工智能生成合成内容标识办法》（2025-09 施行），各平台对 AI 生成封面普遍要求勾选"AI 辅助/AI 生成"声明——交付时提醒用户在上传页勾选。

## 排字兜底（B 模式）

Seedream 排字偶发错字/字形崩坏时使用：

```bash
python3 <技能基目录>/scripts/overlay_text.py 底图.jpg \
  --title "书名" --author "{第0步确认的作者}" --title-size 230 --out 封面-叠字版.jpg
```

字体自动回退链：华文黑体(Medium) → 冬青黑体 → 宋体 → Arial Unicode；书名顶部居中带描边，署名底部居中「{作者} 著」。

## 派发规则

- 子智能体每次派发都是全新会话：prompt 自包含（路径、基准文本、清单），不得写"如前所述"。
- 并发 ≤3（全局 AGENTS.md）；多张封面质检可派 1 个 vision 批量做，也可分批。
- 与用户交流一律中文。

## 质量要求

- 书名字形错误零容忍：质检发现一个错字即判废，转 B 模式。
- 高清原图必须保留（1536×2048）：平台未来可能提高规格，且宣传物料需要高清源。
- 每次 GATE 重生成不超过 2 轮，仍不满意时回到第 2 步换主视觉方向，而不是继续换 seed 碰运气。
- API Key 与任何含 Key 的输出不得写入落盘文件（全局安全红线）。
