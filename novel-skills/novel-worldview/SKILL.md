# 世界观设定工作流

世界观为故事服务，不是百科全书。每一条设定都要回答：它给主线制造了什么冲突、给主角留了什么升级空间。用 TodoWrite 跟踪。

## 前置检查

- 必读已确认的 `books/<book>/settings/大纲.md`：世界观必须装得下九节点，尤其中点真相、至暗时刻、总高潮的舞台。
- 若已有调研报告，参考其中读者对该题材设定的偏好与雷点。

## Pipeline

1. **修炼/力量体系 — dispatch `planner` 或主智能体自作**
   - **境界命名与层级**：大境界数量（6–9 个为宜）+ 每境细分小层（初中后期/九星）；命名体系要统一气质（道家味/武道味/科技味）
   - **突破条件**：每一境突破需要什么（资源/感悟/机缘/杀劫），条件即剧情——没有条件的突破不配当高潮
   - **寿元与代价**：境界对应寿元；突破失败的代价（走火/折寿/废修为）——代价制造至暗时刻
   - **战力量级标尺**（最重要）：每一境的破坏力与世俗对照写清楚，例："炼气＝十人敌，筑基＝百人敌可开山，金丹＝千人敌一方巨擘，元婴＝灭城级，一念镇国"。**量级表是全书战力不崩的锚**
   - **越级规则**：常规修士越 1 小层战斗即为天才；主角金手指最多越几级、代价是什么——写死，防止战力膨胀
   - **境界压制与破绽**：高境对低境的压制表现；以弱胜强的合法途径（地利/阵法/克制/重伤）
2. **实力划分与阶层对照** — 修炼境界 ↔ 世俗权力（王朝/宗门职位）↔ 社会地位的三栏对照表；主角每一卷所处阶层与"仰望的上一层"。
3. **世界地图与舞台动线** —
   - 按大纲分卷框架画分区：大陆/界域 → 区域 → 核心地点（每卷舞台 5–10 个具名地点）
   - **地图即升级路线**：主角动线从边缘到中心（小城 → 王都 → 宗门 → 中央大陆 → 禁地/上界），每个区域标注战力天花板与机缘等级
   - 禁地、秘境、上古战场等"可反复取用的冒险资源"分布
4. **势力组织** — 每区域 2–4 个势力（宗门/世家/王朝/魔道/隐世组织），各自立场、与主角的恩怨预设、镇守战力；幕后终极势力留白指向总 BOSS。
5. **资源与经济** — 货币体系（灵石分级/兑换比）、丹药法器功法分级命名（统一命名法，如法器分黄玄地天四阶）、主角前期主要收入来源。
6. **底层规则与大坑** — 天道/飞升/远古秘辛等 2–4 个贯穿全书的世界级谜团，与大纲中点真相、总高潮挂钩，编号登记为伏笔。
7. **一致性自检 — dispatch `reviewer`**：境界天花板是否容得下总高潮战力、地图是否覆盖全部卷的舞台、资源体系能否支撑主角每卷的成长消耗、有无同境界量级前后矛盾。
8. **落盘** — 写入三个文件（目录不存在则创建），文件头 `状态：草稿`：
   - `settings/世界观/修炼体系.md`（含力量体系 + 战力量级标尺 + 越级规则 + 阶层对照）
   - `settings/世界观/地图与势力.md`（分区地图文字版 + 动线 + 势力档案）
   - `settings/世界观/资源与规则.md`（货币/丹药/法器分级 + 世界底层规则与大坑登记）
9. **GATE** — AskUserQuestion：批准 / 调整（尤其让用户过目境界命名与量级标尺）。批准后状态改 `已确认`。
10. **交付** — 文件路径 + 体系一览摘要；建议下一步 `/novel-characters`。

## 修炼体系文件结构（照此模板写）

```markdown
# 世界观 · 修炼体系（状态：草稿）

## 1. 境界总览
| 大境界 | 小层 | 突破条件 | 寿元 | 战力量级（世俗对照） | 社会阶层 |
（每一行都填满，量级列禁止留空——它是战力锚点）

## 2. 战力量级标尺
（各境界的具体能力表现：速度/破坏/恢复/飞行/神识范围，给正文写作可引用的画面基准）

## 3. 越级与压制规则
（常规越级上限 / 主角金手指越级上限与代价 / 以弱胜强合法途径清单）

## 4. 突破的代价与失败后果
（为压抑情节和至暗时刻预留的机制）

## 5. 特殊体系（可选）
（体修/剑修/魔修/双修等差异化路线，与主流的关系）
```

## 质量要求

- **量级标尺一经用户确认不可轻易改动**：正文吃书多数死于战力崩坏，此表是 `/novel-chapter` 写战斗时的强制参照。
- 命名避免与知名作品撞车（刻意蹭近似命名会显得山寨，调研报告的竞品名单要对照排除）。
- 三个文件合计 300–600 行：每卷用得上的设定才算数，纯背景板设定一句带过。
