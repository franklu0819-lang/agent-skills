# 小说总大纲工作流

产出一份三幕式全书总大纲：一句话故事能让人眼睛一亮，九个关键节点撑起骨架，分卷框架和爽点节奏保证写到一百万字不崩。用 TodoWrite 跟踪。

## 前置检查

- 调研报告存在（`books/<book>/research/`）则必读，采纳已确认的差异化方向；不存在可继续，但要在 GATE 时提醒用户"跳过了调研"。
- `<book>` slug 必须确定；已有目录则沿用。

## Pipeline

1. **核心概念** — 先写出并打磨这五件套（这是大纲的心脏，值得反复推敲）：
   - **一句话故事**：主角 + 目标 + 障碍 + 钩子，例："被夺走帝骨的废柴少年，靠吞噬仇敌修为逆袭，一路打上九天讨回公道。"
   - **金手指**：能力、限制、代价、成长性（有限制的金手指才能撑起三百万字）
   - **核心冲突**：贯穿全书的对抗（个人恩怨 → 势力对抗 → 天道级真相，层层升级）
   - **题材标签**：给读者的一句话卖点（发给书友能安利的程度）
   - **体量规划**：预计卷数与总章数（网文常见：每卷 40–80 章、每章 2200–2500 字）
2. **三幕九节点骨架** — 按下方"三幕式框架"设计，每个节点写 3–5 句：发生了什么、主角得失、读者情绪目标。
3. **分卷框架** — 每卷一行：卷名、舞台（地图升级：村→城→宗门→大陆→界域）、卷主题、本卷主要反派、卷末高潮与大钩子、对应全书三幕的哪一幕。
4. **爽点节奏总设计** — 列全书大爽点（卷级高潮）清单 + 压抑铺垫原则；标注爽点类型轮换，避免连续同款。
5. **审稿 — dispatch `reviewer`**，重点：三幕比例是否失衡、中点与至暗时刻是否够狠、反派梯度是否与主角成长匹配、有无烂尾风险（坑 > 回收能力）、爽点间隔是否超过 3 章。
6. **修订** — 修复 reviewer 提出的高优先级问题，最多 3 轮。
7. **落盘** — 写入 `books/<book>/settings/大纲.md`，文件头 `状态：草稿`。
8. **GATE** — AskUserQuestion：批准 / 调整。批准后把状态改为 `已确认`。
9. **交付** — 大纲路径 + 骨架摘要；建议下一步：`/novel-style`、`/novel-worldview`（两者可先后进行，之后 `/novel-characters`）。

## 三幕式框架（长篇网文适配版）

比例按全书篇幅切分；卷数多时第一幕≈第 1 卷，第二幕≈中间各卷（每卷自成"卷内三幕"，细节由 `/novel-volume` 展开），第三幕≈最后 1–2 卷。

**第一幕 · 建置（约 15–20%）**
1. **开场状态**：主角日常 + 缺陷 + 渴望（三章内必须完成人设立住）
2. **激励事件**：打破日常的不可逆意外（退婚、夺舍、灭门、捡到至宝）
3. **第一情节点**：主角被推入新世界，不可回头（拜入宗门/踏上逃亡/立下血誓）

**第二幕 · 对抗（约 60%）**
4. **玩闹与试探**：新规则学习、初次立威、结识盟友（小爽点密集区）
5. **中点**（全书 50% 处）：假胜利或假失败 → 重大真相反转，主角由被动挨打转为主动出击（身世、阴谋、金手指真相）
6. **敌人升级**：反派规格逐级抬高，连环压迫，盟友遇险
7. **至暗时刻（第二情节点）**：失去最重要的东西（师长陨落/金手指失效/挚友反目），信念重建

**第三幕 · 解决（约 20–25%）**
8. **最终决战**：三段式高潮——初战受挫 → 伏笔合拢/力量觉醒 → 总爆发碾压
9. **结局**：新平衡 + 更大世界的钩子（为续作留口，不挖新坑）

## 大纲文件结构（照此模板写）

```markdown
# 《书名》总大纲（状态：草稿）

## 0. 一句话故事与核心概念
（一句话故事 / 金手指 / 核心冲突 / 题材标签 / 体量规划）

## 1. 主线与三幕九节点
### 第一幕 · 建置
- 节点1 开场状态：……
- 节点2 激励事件：……
- 节点3 第一情节点：……
### 第二幕 · 对抗
- 节点4…节点7（同上格式）
### 第三幕 · 解决
- 节点8…节点9（同上格式）

## 2. 分卷框架
| 卷 | 卷名 | 舞台 | 主题 | 主要反派 | 卷末高潮与钩子 | 所属幕 |

## 3. 全书爽点节奏
- 大爽点清单（卷级）：卷1→卷2→…
- 节奏原则：3 章一小爽 / 10 章一小高潮 / 卷末大高潮；大爽前 1–2 章必须铺垫压抑
- 爽点类型轮换表

## 4. 主线之外
- 感情线走向、世界观大坑（→ 由 /novel-worldview 展开）、主要伏笔清单（编号登记）
```

## 质量要求

- 每个节点必须回答"读者此刻的情绪是什么"——情绪目标缺失的节点等于没设计。
- 金手指必须写限制与代价；无限制的金手指会在第二幕杀死悬念。
- 分卷框架里的反派战力必须低于或等于主角该卷末的成长上限 + 一档（压制太久憋屈、翻车太易廉价）。
- 大纲 200–400 行为宜：写到"每卷能展开成卷纲"的粒度即可，章级细节是 `/novel-volume` 的事。
