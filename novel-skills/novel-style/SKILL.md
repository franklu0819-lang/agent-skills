# 写作风格设定工作流

风格指南是每一章正文写作时的"尺子"：`/novel-chapter` 会逐条对照它。设定得好，一百章之后文风依然统一；含糊带过，每章都像不同的人写的。用 TodoWrite 跟踪。

## 前置检查

- 必读 `books/<book>/settings/大纲.md`（状态须为已确认）：题材与情绪基调决定文风取向——都市爽文短平快，仙侠正剧可容留白，悬疑要冷色调克制。
- 若用户对风格已有明确偏好（"要番茄风""要老派仙侠味"），以其为准适配以下条目。

## Pipeline

1. **逐项定夺** — 与用户过一遍风格要素，分歧大的项用 AskUserQuestion 给候选：
   - **叙事视角**：默认第三人称限知跟随主角；若选多视角/第一人称，写明切换规则与频率上限
   - **文风基调**：句式（短句为主，平均句长建议 15–25 字）、节奏（快切入慢高潮）、画面感来源（动作与五感，而非形容词堆砌）
   - **对白规则**：口语化、每人有辨识度（口头禅/说话习惯）、对白必须推动冲突或塑造人物；反派"装逼台词"要为后文打脸蓄力
   - **描写密度**：战斗与爽点场景详写（占篇幅 60% 以上），转场略写；单段环境描写 ≤3 句；回忆插叙 ≤200 字且必须服务于当下冲突
   - **爽点呈现笔法**：铺垫—压抑—爆发三段式；爆发时写具体画面不写抽象形容；**旁人反应衬托**（旁观者的震惊/嫉妒/服气是爽感的放大器）
   - **情绪词汇表**：本书高频情绪用词与禁用词（禁"顿时""瞬间"滥用、禁网络烂梗、禁出戏的现代词——除非都市题材）
2. **写示例段** — 亲自写 3 段各 200–400 字的示范正文，钉死笔感：
   ① 打脸爽点段（含旁人反应）② 日常对白段（人物辨识度）③ 突破/战斗段（动作画面感）
   示例段是风格指南的核心资产——比任何形容词描述都有效。
3. **落盘** — 写入 `books/<book>/settings/风格指南.md`，文件头 `状态：草稿`。
4. **GATE** — AskUserQuestion：用户认可示例段笔感即批准（不认可就按意见重写示例段，最多 3 轮）；批准后状态改 `已确认`。
5. **交付** — 路径 + 要点摘要；建议下一步 `/novel-worldview`（若已完成则 `/novel-characters`）。

## 风格指南文件结构（照此模板写）

```markdown
# 《书名》写作风格指南（状态：草稿）

## 1. 叙事视角与结构
（人称、视角、时态习惯、章节内部节奏配比：开场承接15% / 推进铺垫40% / 爽点爆发30% / 收尾钩子15%）

## 2. 文风基调
（句式规则、节奏规则、画面感来源、段落长度习惯）

## 3. 对白规则
（口语化标准、人物辨识度手段、装逼—打脸台词结构）

## 4. 描写密度红线
（战斗/日常/转场/回忆各自的篇幅纪律，写明数字上限）

## 5. 爽点呈现笔法
（三段式写法、旁人反应衬托法、爆发段禁忌——禁写"经过一番激战"式跳过程）

## 6. 章末钩子规范
（四类钩子定义：危机钩/悬念钩/期待钩/反转钩；最后一句的力道要求）

## 7. 词汇表
（推荐用词 / 慎用词 / 禁用词，含题材专属术语的用法约定）

## 8. 风格示例段（核心资产）
### 示例一：打脸爽点段
### 示例二：日常对白段
### 示例三：突破战斗段
```

## 质量要求

- 所有纪律写成可检查的数字（"单段环境描写 ≤3 句"），不写"描写要精炼"这类无法核验的话——`/novel-chapter` 要逐条自检。
- 示例段必须自己动笔写，不得摘抄任何已发表作品。
- 指南 150–300 行；超长说明纪律定得太碎，合并同类项。
