# 人物角色及关系设定工作流

读者记住的从来不是设定，是人。每个主要人物都要有"让读者愿意追看的功能"：主角承载代入感，反派制造压抑，女主承载情感线，配角制造趣味与情报。用 TodoWrite 跟踪。

## 前置检查

- 必读已确认的 `settings/大纲.md`（九节点对人物的需求）与 `settings/世界观/`（战力与势力框架）。
- 人物必须长在世界观里：出身势力、修为成长路线、所在地图动线都要对得上。

## Pipeline

1. **主角档案** — 逐项设计并落盘：
   - 基础：姓名（易读易记、不生僻）、年龄、出身、外貌特征 2–3 个（重复出场时锚定形象用）
   - **性格三件套**：核心特质（如睚眦必报/沉稳苟道）+ 性格缺陷（缺陷制造麻烦，麻烦制造剧情）+ 处事底线（读者的爽感来自主角"永远做读者想做的事"）
   - **核心动机**：他要什么、为什么是现在、愿意付出什么（动机逐幕升级：求生 → 复仇 → 守护 → 抗争天道，与大纲三幕对齐）
   - **成长弧线**：每一幕结束时主角的心境与能力坐标（能力成长由修炼体系给坐标，心境成长由人物弧线给）
   - 金手指档案（与大纲一致：能力/限制/代价/解锁节奏——**分卷解锁表**，每卷解锁一档，对应本卷爽点升级）
   - 口头禅 / 标志性小动作（辨识度资产，正文中反复调用）
2. **感情线角色** — 1–2 位主要情感线人物：与主角的相遇节点（对应分卷）、关系推进里程碑、各自的秘密与代价；感情线必须缠绕主线（帮过也坑过），不做纯挂件。
3. **反派梯队** — 与大纲分卷框架一一对应：
   - 每卷 1 个主反派 + 1–2 个跳板反派（前期被踩的"嚣张 NPC"）
   - 每个主反派：身份战力、与主角的恩怨起点、逼格展示场景（先立后破）、结局（被打脸的方式要配得上他嚣张的程度）
   - 幕后 BOSS：真身、与中点真相/总高潮的挂钩、前中期如何借手下出场刷存在感
   - **反派梯度检查**：下一卷反派的威胁必须高于上一卷（含心智层面，不只是境界数字）
4. **配角团队** — 师尊/前辈（金手指外的引路人，至暗时刻的代价候选人）、损友/兄弟、机灵鬼/搞笑担当、对手转盟友；每人一句"功能定位"，防止写成路人。
5. **关系网图谱** — 文字版：阵营块（主角团/各反派/中立势力）+ 恩怨链（A 杀了 B 的师尊 → B 是主角盟友 → 该仇如何影响主角）+ 感情线三角关系（若有）。
6. **出场登记表** — 全部具名人物一张表：姓名 / 阵营 / 首次出场（卷/章预估）/ 功能 / 状态（活跃/退场/死亡）。**这是防"写着写着人丢了"的台账**，后续由 `/novel-chapter` 持续更新。
7. **审稿 — dispatch `reviewer`**：人物弧线与三幕对齐吗、反派梯度与大纲卷框架匹配吗、金手指解锁节奏与卷高潮匹配吗、有没有功能重复的废人设。
8. **落盘** — 写入 `settings/人物/`（目录不存在则创建），文件头 `状态：草稿`：
   - `主角-<人名>.md`（文件名必须含主角姓名，如 `主角-江渡.md`）、`重要角色-<人名>.md`（女主/师尊/宿敌各一档）、`反派梯队.md`、`关系网.md`
9. **GATE** — AskUserQuestion：批准 / 调整。批准后全部改 `已确认`。
10. **交付** — 文件路径 + 人物一览摘要；建议下一步 `/novel-volume` 开始第一卷卷纲。

## 主角档案模板（照此写）

```markdown
# 人物档案 · 主角：<姓名>（状态：草稿）

## 基础信息
姓名 / 年龄 / 出身 / 外貌锚点 2–3 个 / 修行资质设定

## 性格
核心特质：……（附 1 个能体现该特质的行动示例）
性格缺陷：……（它会在本卷引发什么麻烦：写 2 个）
处事底线：……（什么事他绝不做 / 什么事一定做）

## 核心动机与成长弧线
| 幕 | 他要什么 | 心境坐标 | 能力坐标（境界） |
（与大纲三幕对齐）

## 金手指档案
能力 / 限制 / 代价 / 分卷解锁表（每卷解锁一档，对应本卷爽点升级）

## 辨识度资产
口头禅：……
标志性动作：……
说话习惯：……
```

## 质量要求

- 每个主要人物必须有缺陷与代价——完美人设没有剧情，也立不住。
- 反派的"逼格展示"场景必须先于打脸至少 1–2 章（压抑铺垫原则在人物层的落地）。
- 人名、境界、势力名写作前与 `世界观/`、`大纲.md` 交叉核对，零冲突。
- 总量控制：具名人物首批 ≤15 人，其余写到再补档——登记表是活的，不是一次写满。
