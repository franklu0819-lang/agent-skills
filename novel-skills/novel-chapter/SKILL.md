# 章节编写工作流

按已确认的卷纲逐章产出正文。核心纪律：**字数落在 2200–2500 区间、爽点在场、钩子收尾、不吃书、AIGC 人工占比 > 80%**——五项全过才算写完一章。用 TodoWrite 跟踪（批量写章时每章一个 todo）。

## 前置检查（缺一不可）

- 本卷 `卷纲.md`（已确认）——找到目标章在排布表中的那一行
- `settings/` 三件套（风格指南 / 世界观 / 人物）——已确认状态
- **上一章正文**（非首章时必读）：开头必须承接它的章末钩子
- `progress.md`——伏笔台账中本章需要操作的编号

用户未指定章号时：默认写 `progress.md` 记录的下一章，向用户复述"接下来写第 N 章《标题方向》"再动笔。

**改道规则**：目标章为第 001–003 章时，引导用户改用 `/novel-opening`（黄金三章精写流程：蓝图 GATE + 连读自检 + 编辑留存审稿），不要用本技能直接写开篇。

## Pipeline（每一章完整走一遍；批量 = 顺序循环，严禁并行写多章——章与章有前后依赖）

1. **备料** — 读卷纲本章行 + 上一章正文最后 500 字 + 本章涉及人物的档案 + 涉及设定（境界量级、地点、物品）。把本章四要素抄在开工处：事件 / 冲突 / 爽点（类型）/ 钩子（类型）。
2. **写作** — 按下方"章内结构与节奏"落笔，全程对照风格指南的数字红线。
3. **自检与修** — 逐项回答（写进交付说明，不是心里想想）：
   - 本章爽点是什么？压抑铺垫在哪几段？
   - 章末钩子是哪一句？属于四类中哪一类？
   - 人名/境界/地名/物品/人物形象与档案核对结果？**新出场具名人物"首见必落形"**（见下方红线）：首次出场未落形象锚点即视为未过自检。
   - 与上一章最后一幕是否无缝衔接？
   - **AI 味自查**：对照下方"去 AI 味纪律"逐项过，重点扫**开头 300 字**与**背景交代段**（历史实锤的两个高判区）；发现禁句当场改，缺毛边当场补；**编辑后必查重**——行号/替换操作完成后 grep 重复句段（历史事故：新旧段叠加导致 AI 判值飙高），编辑一律用精确文本匹配、禁用行号定位。
4. **字数验证（硬门槛，必须展示证据）** — 运行本技能自带脚本（位于本技能目录下 `scripts/count_han.sh`，技能加载时会给出基目录；**门槛＝每章 2200–2500 字·非空白字符口径**（含标点与字母数字，只扣空格换行，与线上 word_count 同口径——2026-10-01 用户定标；<2200 不足、>2500 超长，均为不达标；纯汉字数作辅助参考一并输出）：
   ```bash
   bash <技能基目录>/scripts/count_han.sh <章节文件路径>
   ```
   若脚本无法定位，退回内联命令：`perl -CSAD -ne '$n += () = /\p{Han}/g; END { print $n // 0 }' <文件>`。
   - <2200（不足）：当场扩写冲突过程或爽点细节（禁止注水对话和重复描写凑字），复测直到入区间
   - >2500（超长）：删减非必要闲笔与重复信息（不动爽点与钩子），复测直到入区间；>3000 优先按卷纲拆为两章
5. **落盘** — 写入 `volumes/第NN卷-<卷名>/chapters/第NNN章-<标题>.md`（NNN 三位数章号；标题从卷纲"标题方向"定稿）。
6. **AIGC 检测（硬门槛）** — **外部依赖**：`aigc-detect` 技能（不在本仓库；朱雀文本检测，key 配在 `~/.zshrc` 仅交互式 zsh 加载，必须用 `zsh -ic` 调用）。脚本按顺序定位：~/.zcode/skills/aigc-detect/scripts/detect.py → ~/.agents/skills/aigc-detect/scripts/detect.py：
   ```bash
   zsh -ic 'python3 <aigc-detect 技能目录>/scripts/detect.py <章节文件路径>'
   ```
   - 通过线（2026-09-17 用户指令）：**① 无 AI 特征级片段（任何段落 AIGC ≥0.99 即不通过）；② 疑似 AI（0.5–0.99）片段字数占全章比例 < 40%**，即人工特征占比 > 60%。检测不达标 = 本章没写完。
   - 不达标循环：跑 `--no-merge` 定位 label=1/2 的高 AI 段落 → 按"降 AIGC 五手法＋结构四招"**只改写这些段落**（禁整章重写，防破坏已通过部分；同一引导句式禁连用、编辑后必查重）→ 复测字数 → 整章复检，循环至达标；同一片段缝补超过 3 轮仍不过时，停止缝补、该段推倒重写。
   - 历史经验：开头 300 字最易反复判高，优先用"毛边清单"加固；达标即收手，不为压更低占比反复空烧额度。
   - 例外：检测接口不可用（网络/额度耗尽）时如实告知用户，由用户决定是否先交付后补检——不得静默跳过。
7. **登记与交付** — 更新 `progress.md`（完成表记录本章最终人工占比 + 伏笔操作 + 人物出场登记若有新具名人物）；交付 = 章节路径 + 字数证据 + **AIGC 检测证据（最终人工占比，多轮时列每轮）** + 自检五答 + 一句下章预告。单章任务到此结束；批量任务继续下一章（每章独立完成 1–7 步）。

## 章内结构与节奏（2200–2500 字的分配）

- **开场承接（约 15%）**：上一章钩子的直接延续，3 行内进入具体场景；禁大段回忆、禁环境描写开头超过 3 句。
- **推进与铺垫（约 40%）**：冲突升级、对手施压或立威（压抑蓄力——爽点的势能来自这里）、主角底牌若隐若现；穿插必要的设定信息（以对话和动作带出，禁百科式说明文）。
- **爽点爆发（约 30%）**：写具体过程与画面，拆到可见的动作与感官细节；**必须写旁人反应**（震惊/失态/嫉妒/叹服）放大爽感；节奏放慢、句子放短、镜头拉近。
- **收尾钩子（约 15%）**：新危机露头 / 关键悬念抛出 / 明日大事预告 / 最后一句反转；最后一句必须是强刺激点，戛然而止。

## 写作红线（逐条来自项目 AGENTS.md、风格指南与历史审稿实锤）

- 视角锁定第三人称限知跟随主角；爽点爆发段禁写"经过一番激战""不出意外的话"式跳过程。
- 对白推动冲突或立人设，闲聊对白删除；每个人物说话带辨识度（人物档案的口头禅/习惯）。
- 战斗必须对照 `世界观/修炼体系.md` 的量级标尺——越级上限、破坏表现不得超标（吃书零容忍）。
- 禁词与慎用词以风格指南词汇表为准；禁注水：同一信息不得在章内重复出现两次。
- **首见必落形（人物形象红线）**：具名人物首次出场必须落形象锚点——体貌＋标识物至少各一（人物档案的外貌锚点优先，如"厚茧手＋无名指旧疤＋立领褂子"式辨识组合），年龄感同步落地。限知视角下禁自照镜子式硬写，走三种装置带出：①**他人反应**（递物时对方目光一顿、握手一愣）；②**镜面反光**（柜台玻璃/水面/监控里认出背影）；③**随身物件**（磨边的袖口、边角发白的文件袋、被摩挲的旧疤）。禁"他有一双粗糙的手，穿着一件…"清单式罗列（静态罗列=AI 高判型）。历史实锤（2026-10-01《我的木偶会还愿》开篇三章用户审稿）：对话写得太顺导致整章"只有语言没有形象"，主角三锚点一个未落，读者读完不知主角年龄样貌——补写七处方过。对白越出彩的章越要自查这一条。

## 去 AI 味纪律（每章自检清单；细则以风格指南 §2 为准）

**五禁（写出即改）**：
1. 禁每句断行（单句成段每章 ≤3 处关键转折）、禁意象轰炸（一场景一喻）、禁高级感用力过猛；
2. 禁顿悟腔——"这就够了""仿佛一直在等他抬头"式抒情短句孤段，情绪一律用动作落地；
3. 禁 AI 高频句式——"是被××的"被动强调开场、"就在这时"高频转折、双比喻叠加（"像 A，又像 B"）、"莫名的××"书面腔、宏大比喻（深渊/巨浪级）不用在主角身上；
4. 禁仿古结构——"晃了两晃/看了两看"叠动、"差点灭"式省略、"发落""咽的气"式错搭，一律正常口语；
5. 禁背景一段塞满（信息密度均匀=高 AI）——背景拆碎，混入情绪与怨气给；**禁旁白心理代述（最高频 AI 判因，历史实锤 0.81 片段）**——任何人物心思（反派算计/路人态度/主角总结）一律转为人群耳语、嘀咕或动作，旁白只写看得见听得着的东西。

**降 AIGC 五手法（重写高片段时逐条用）**：
①闲笔（"烧到第三沓纸""平日连只野猫都不爱来"——AI 不写"没用"的话）；②主观视角替代说明文（"不用看第二眼"替代"来的人是××"）；③对白口吻糙化（"我说了"→"我白日里是怎么说的"）；④信息拆碎带情绪（"如今看来，连这一句也做不得数"）；⑤短句毛边（"他站起身。"独立成行）。

**毛边清单（开头 300 字必配 ≥2 项）**：内心吐槽孤段（"来得可真快。"）／人名孤段（"周奎。"）／口语碎片起句（"不用看第二眼。"）／反讽 OS（"今晚倒热闹"）／怨气短句（"老人走了才三天，尸骨还没凉透，这楼在族里嘴里就已经是库房了"）。核心：句子要"绊"得住，段落长短不规则，情绪先于信息。

**高判区（历史实锤）**：①章开头 300 字；②背景交代段；③觉醒/突破段（易意象化）；④**独角戏段（0.95 实锤）**——终极判因是**叙述/对话比例**：002 过关片段对话占比 >50%，003 卡死片段仅 6%；单人场景的对话对象可以是**亡者/遗物/自己**——"对牌位说话"（"裴爷爷，我动你东西了啊""石子捡这个做什么？打狗？"）＋自问自答式（"给谁？谁会要？""夜风没理他。你倒是早点说啊。他自己接了一句"），把独白流改造成无回答式对话，目标对话占比 ≥25%；——连续 500 字以上无现场对话的匀速叙述是 AI 特征级判因，每千字至少安排一次现场对话（可引入最小配角：杠夫、门房、掌柜）；三区写完先自查一遍再进自检步骤。**无用之物手法**：给场景配一个不服务剧情的细节（老裴的磨圆石子、木板碑"等抚恤再补"）——AI 不写没用的东西。**002 章通关五轮实录（方法论定稿：修章顺序=先结构后局部）**：第 1-2 轮修句式无效（0.79→0.83）→第 3 轮动结构通过（0.37）：非线性叙述（场景嘈杂先于人物定位）＋私人记忆闲笔前置带信息＋泼皮碎台词（禁标题式概括句）＋叙述者冷幽默＋物理反馈代情绪→第 4-5 轮局部清尾：模板句（声音不高却字字清楚）／成语（面如死灰）／叙述者总结句对白化（"今日这热闹，值"）／排比骨架插打断点（背条文卡壳＋执事当真翻册）。
**单人过渡章根治法（003 第三轮实录：补丁无效，0.78→0.66 卡住、收尾段反升）**：①打补丁自救无效——单人事务流水骨架必须配一个"话痨工具人"配角贯穿 30% 以上篇幅（杠夫问答五组、市井评点"倒像个小东家"）；②回忆段一律对话化（把"老裴压低声音说夜里练"改成有两问两答的当晚对话）；③收尾段禁绵长抒情（情绪段最多两连，之后必须动作收）；④警惕补丁自伤——新加的句子同样过五禁（"心里发紧"＝心理代述、"骂骂咧咧地摔门"＝模板市井句、改写引入重复句）。
**解谜流水段与抒情收尾链降 AI（003 第四五轮实录：杠夫贯穿段 0.28 大胜验证）**：①解谜发现段（逐件发现 A→B→C）＝惊魂虚惊（脚步声→捏刀贴门→虚惊→手心汗）＋发现挫折（第一次没旋开）＋预期落空（以为秘籍/私房钱→都不是）三件套；②抒情收尾链＝生理细节打断（修炼后口渴下楼灌半瓢凉水）＋背景音实体化（梆子声由远及近他数着）＋发现感改写（"咦，不疼了。又按重了些"替代程式化验伤）。
**独角戏/事务清单章（003 实录）四刀**：①主角警觉小节（刚遭变故的人对动静的过激反应——风声→抄刀）；②小狼狈（纸边割手吮指、灯油将尽挑芯）；③发现过程笨拙化（辨认天枢：横看竖看、对灯照、靠回忆认出——不写"他认出来了"）；④世界声音注入（远处狗吠、摔门声）＋清高频副词（每章"轻轻/缓缓/微微"合计 ≤1 处）。
**顽固高片段（修句式无效时）三招**：①改叙述顺序（非线性：先场景嘈杂/结果，后定位人物；私人记忆闲笔前置带信息，替代旁白解释）；②台词拆碎（控诉要破碎重复带口气词，禁标题式概括句）；③叙述者冷幽默（"他自己举着自己的名帖，浑然不觉有什么不对"）＋物理反馈代情绪（烛花爆了没人剪）；④剧情必需的排比结构（三问、三段控诉）降 AI 法——骨架不动，插打断点：背文卡壳（"第七条：停灵之期，任何人不……不惊扰亡者"）、旁人当真翻册验证、抢话打断。
