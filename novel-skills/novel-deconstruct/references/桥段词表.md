# 桥段词表（拆书 L4 打标用）

统一标签集。拆书时只用本表标签打标，禁止自造同义词（发现缺口时先在本文档登记再使用）。

## 爽点型桥段

| 标签 | 含义 | 典型场景 |
|---|---|---|
| 打脸 | 被轻视者当众反杀预期 | 退婚/宴席/拍卖会 |
| 扮猪吃虎 | 隐藏实力被反复试探 | 低调新人入强者局 |
| 身份反转 | 真实身份在关键时刻揭晓 | 上门女婿/扫地僧 |
| 越阶碾压 | 低境界胜高境界 | 以弱胜强的战斗 |
| 夺宝 | 稀缺资源争夺胜出 | 秘境/遗迹/拍卖 |
| 一鸣惊人 | 长期蛰伏后的集中兑现 | 比武/大考/公开演示 |
| 扮演救世主 | 众人绝望时主角入场 | 灭门危机/城破在即 |

## 危机型桥段

| 标签 | 含义 | 典型场景 |
|---|---|---|
| 误解加深 | 信息差导致关系恶化 | 被冒名/被陷害 |
| 真相反转 | 关键信息迟到的揭露 | 仇人竟是至亲 |
| 至暗时刻 | 主角全面失败跌入谷底 | 修为尽失/众叛亲离 |
| 倒计时压迫 | 明确时限下的任务 | 毒发/大比/营救 |
| 两难抉择 | 两个都重要的选项互斥 | 救一人还是救众人 |

## 情绪型桥段

| 标签 | 含义 | 典型场景 |
|---|---|---|
| 迟来的认可 | 长期不被看好后被致敬 | 长辈/对手低头 |
| 故人重逢 | 旧关系在新位面重逢 | 恩人/宿敌多年后再见 |
| 舍命相护 | 以重大代价换取对方安全 | 挡刀/断后 |
| 独自背负 | 主角隐瞒真相独自承受 | 被误解仍护人周全 |

## 钩子型（章末用，L2/L3 也用此表）

| 标签 | 含义 |
|---|---|
| 悬念钩 | 抛出新问题未解答 |
| 危机钩 | 危机爆发在最高点切章 |
| 反转钩 | 章末最后一行颠覆本章认知 |
| 期待钩 | 明示下一章将发生的兑现 |
| 情绪钩 | 在情绪最高点戛然而止 |
